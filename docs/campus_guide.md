# SMIT Peshawar Campus Guide

Campus: Mohsin & Huma Mass IT Training Centre
Location: Opposite Jan's Deli, University Town, Peshawar

## Facilities

- Computer lab with Python and VS Code installed
- Prayer area on the ground floor
- Help desk at reception for ID cards and attendance

## Student tips

- Bring your own laptop if you can; lab machines are shared
- Save API keys in a local `.env` file. Never commit `.env`
- For this module, run the assistant with `python chat.py`
- Type `quit` to leave the chat, `reset` to start a new session

## Who to ask

- Schedule changes: course coordinator
- ADK homework: teaching assistant during Project Lab
- Account / API key issues: instructor office hours (Thursday 5 PM)
